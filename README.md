# 일식 시뮬레이션 (Solar Eclipse Simulation)

브라우저에서 동작하는 **태양–달–지구 일식 시뮬레이터**입니다. 빌드 단계 없이
GitHub Pages에서 바로 동작하는 정적 페이지로 구성되어 있습니다.

## 미리보기

GitHub Pages가 활성화되면 다음 주소에서 바로 실행됩니다:

```
https://devrobertson.github.io/moon-shadow-simulation/
```

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| 좌측 3D 뷰 | 태양·달·지구의 공간 배치를 보여줍니다. 마우스로 회전, 휠로 확대/축소 가능. 빨간 점은 현재 개기일식 중심, 검은 디스크는 반영(부분일식) 영역, 빨간 곡선은 지표면을 따라 누적된 개기일식 경로입니다. |
| 우측 2D 지도 | 등각투영(equirectangular) 지도. 주야 음영, 부분일식 영역(노란 원), 누적 개기일식 경로(빨간 선), 현재 그림자 위치(빨간 점)를 표시합니다. |
| 하단 컨트롤 | 재생/일시정지, 처음으로, 시간 슬라이더(6시간), 재생 속도(0.25×–10×), 단계 표시(개기/부분/없음). |

## 시뮬레이션 모델

- **좌표계**: 태양은 −X 방향에 위치, 황도면은 XZ 평면, 지구 자전축은 X축 기준 23.5° 기울임.
- **그림자 기하**: 태양 → 달 직선이 지구 구체와 교차하는 점을 본영 중심으로 계산. 본영(umbra)·반영(penumbra) 원뿔 반경을 통해 개기/부분일식을 판정합니다.
- **시간 비율**: 지구 자전은 실제 속도(15°/h). 달 공전은 편의상 8배속이라
  6시간 시뮬레이션 창 안에 *일식 없음 → 부분 → 개기 → 부분 → 일식 없음*
  한 사이클이 모두 들어옵니다. 8배속에서도 달의 궤도 각속도는 지구
  자전보다 훨씬 작으므로 그림자는 실제와 같이 **서쪽 방향**으로 움직입니다.
- **개기일식 경로**: 시뮬레이션 시작 시 0–360분 구간을 0.5분 간격으로 미리
  계산하여 슬라이더 스크럽 시 즉시 갱신됩니다.

## 로컬 실행

정적 파일이므로 임의의 HTTP 서버로 띄우면 됩니다:

```bash
python3 -m http.server 8000
# → http://localhost:8000 접속
```

> `index.html`을 `file://`로 직접 열면 브라우저의 ES module CORS 정책 때문에
> Three.js CDN 임포트가 실패합니다. 반드시 HTTP 서버를 통해 열어 주세요.

## GitHub Pages 활성화

1. 레포지토리 **Settings → Pages**
2. **Build and deploy → Source**: *Deploy from a branch*
3. **Branch**: 배포하려는 브랜치 (`main` 또는 작업 중인 브랜치), Folder: `/ (root)`
4. 저장 후 1–2분 뒤 위의 URL에서 접속

`.nojekyll` 파일이 포함되어 있어 Jekyll 처리 없이 그대로 배포됩니다.

## 파일 구조

```
.
├── index.html              # 페이지 레이아웃과 컨트롤
├── style.css               # 전체 스타일
├── .nojekyll               # GitHub Pages용 Jekyll 비활성화
└── js/
    ├── main.js             # 시뮬레이션 본체 (Three.js 장면, 시간 진행, 그림자 기하)
    └── earthTexture.js     # 캔버스 기반 절차적 지구 텍스처
```

## 단순화한 부분

학습용 시각화이므로 다음은 단순화되어 있습니다:

- 달의 궤도 경사(약 5°)는 0으로 두어, 시뮬레이션 시작점은 항상 노드를 통과한
  완전 정렬 상황으로 가정합니다.
- 지구는 점광원으로 조명되며 대기 산란/굴절은 모델링하지 않았습니다.
- 거리 비율은 시각적 가독성을 위해 압축되어 있으나, 태양/달의 시직경이
  지구에서 거의 같도록(개기일식이 가능하도록) 튜닝되어 있습니다.
